# Starkfin-other

Release files for Starkfin-other, a Jellyfin client for TVs based on [litefin](https://github.com/MoazSalem/litefin) (MPL-2.0).

- `updates/`: the signed update files the app downloads (served at https://starker3.github.io/Starkfin-other/updates/).
- Source code: each release under [Releases](https://github.com/Starker3/Starkfin-other/releases) has the source archive it was built from.
